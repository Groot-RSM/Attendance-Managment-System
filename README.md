# Attendance Management System

This repository contains the complete source code for the Attendance Management System. It is divided into two main components:

## 📱 Software
The `software/` directory contains the Flutter application for the system. It includes the user interface, state management, and integrations with Firebase and Bluetooth (BLE) services.

## 🔌 Hardware
The `hardware/` directory contains the Arduino/ESP32 code used for the physical attendance tracking devices, including fingerprint scanning and I2C components.
